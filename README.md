# zapret2applet

**Графическая оболочка для [zapret2](https://github.com/bol-van/zapret2) в Linux.**

Управляйте службой zapret2, подбирайте рабочие стратегии и обновляйте установленную версию через графический интерфейс — без необходимости выполнять эти действия в терминале.

> [!IMPORTANT]
> **Неофициальный проект.** `zapret2applet` не связан с автором и сопровождающими проекта [zapret2](https://github.com/bol-van/zapret2).
>
> Это ранняя версия приложения. Найденные стратегии необходимо вручную перенести в конфигурацию zapret2.

## Возможности

- **Управление zapret2.** Просмотр состояния, запуск и остановка службы одной кнопкой.
- **Подбор стратегий.** Проверка указанных сайтов по HTTP, HTTPS и QUIC с использованием IPv4 и IPv6. Приложение показывает стратегии, которые работают в сети вашего провайдера.
- **Копирование результата.** Найденную стратегию можно скопировать одним щелчком.
- **Системный трей.** После закрытия окна приложение продолжает работать в области уведомлений. Запуск и остановка доступны из меню значка.
- **Автозапуск.** Можно настроить запуск службы zapret2 при загрузке компьютера и запуск приложения при входе в систему. При автоматическом запуске приложение сворачивается в трей.
- **Проверка обновлений.** Приложение раз в сутки проверяет наличие новых релизов на GitHub. Установленный zapret2 можно обновить до последнего релиза; загруженные файлы проверяются по контрольным суммам.
- **Два языка интерфейса.** Русский и английский; язык выбирается автоматически по языку системы.

## Установка

### 1. Установите zapret2

Установите zapret2 по [официальной инструкции проекта](https://github.com/bol-van/zapret2). Обычно программа устанавливается в каталог `/opt/zapret2`.

### 2. Скачайте и установите пакет

Откройте страницу [Releases](https://github.com/avsprv/zapret2applet/releases), скачайте пакет для своего дистрибутива и установите его.

**Fedora (`.rpm`):**

```bash
sudo dnf install ./zapret2applet-*.rpm
```

**Debian / Ubuntu (`.deb`):**

```bash
sudo apt install ./zapret2applet_*.deb
```

### 3. Запустите приложение

Найдите **zapret2applet** в меню приложений и запустите его.

> Если пакет для вашего дистрибутива пока не опубликован, воспользуйтесь [инструкцией по сборке из исходников](#сборка-из-исходников).

## Использование

### Управление службой

На вкладке **«Статус»** можно посмотреть состояние zapret2, запустить или остановить службу, а также настроить автозапуск службы и самого приложения.

### Подбор стратегий

1. Убедитесь, что сайты, для которых требуется подобрать стратегию, указаны в приложении.
2. Нажмите **«Начать подбор»**.
3. Если zapret2 запущен, приложение предложит остановить его на время проверки.
4. Дождитесь завершения тестирования. Оно может занять несколько минут.
5. Просмотрите результаты и скопируйте подходящую стратегию.

Подбор проверяет HTTP, HTTPS и QUIC, а также IPv4 и IPv6. Найденную стратегию нужно вручную перенести в конфигурацию zapret2.

### Обновление

На вкладке **«Обновления»** доступны действия **«Проверить обновления»** и **«Обновить»**. Автоматическую ежедневную проверку обновлений можно отключить.

## Почему приложение запрашивает пароль администратора?

Основной интерфейс работает от имени обычного пользователя. Для отдельных операций требуется повышенный уровень привилегий. Их выполняет вспомогательный модуль, а система запрашивает пароль администратора через механизм авторизации.

Пароль может запрашиваться при следующих действиях:

- запуске и остановке службы;
- подборе стратегий;
- обновлении zapret2.

При обновлении запрос авторизации появляется каждый раз: операция заменяет файлы, которые впоследствии запускаются с правами `root`.

## Сборка из исходников

### Зависимости

**Fedora:**

```bash
sudo dnf install cmake ninja-build gcc-c++ qt6-qtbase-devel qt6-qttools-devel polkit
```

**Debian / Ubuntu:**

```bash
sudo apt install build-essential cmake ninja-build qt6-base-dev qt6-tools-dev qt6-l10n-tools pkexec
```

### Сборка и установка

```bash
git clone https://github.com/avsprv/zapret2applet.git
cd zapret2applet

cmake -S . -B build -G Ninja
cmake --build build

sudo cmake --install build --prefix /usr
```

После сборки приложение можно запустить без установки:

```bash
./build/zapret2applet
```

При запуске из каталога сборки диалог авторизации не будет содержать подробного описания действия. После установки приложения в систему диалог отображает понятное описание операции.

Инструкции по созданию пакетов `.deb` и `.rpm` находятся в [`packaging/README.md`](packaging/README.md).
